Install Manually

While the browser store reviews are pending, you can download the ready-to-load extension package directly and install it in about a minute:

Download for Chrome & Edge (.zip) Download for Firefox (.zip)

Google Chrome & Microsoft Edge

  1. Download nursery-media-downloader-chrome-edge-mv3.zip above and unzip it into a permanent folder (e.g. inside Documents).
  2. Open chrome://extensions (or edge://extensions in Edge).
  3. Turn on the Developer mode toggle in the top-right corner.
  4. Click Load unpacked and select the unzipped folder.

Mozilla Firefox

  1. Download nursery-media-downloader-firefox-mv3.zip above.
  2. Open about:debugging#/runtime/this-firefox in Firefox.
  3. Click Load Temporary Add-on… and select the downloaded .zip file (or unzip it and select manifest.json).
For developers: building the .zip from source 
git clone https://github.com/rob-n-f/Nursery-Browser-extension.git
cd Nursery-Browser-extension
npm install
npm run dev

Open http://localhost:3000 and export the packages from the Store Publishing Kit tab.

How to Use After Installing

  1. Log in to Bright Horizons FamilyApp or Famly and open your child's Learning Journey or Newsfeed. (If your child has already graduated, go to Previous Children first.)
  2. Click the floating Download Media button in the bottom-right corner (or click the extension icon in your browser toolbar).
  3. Optionally click Auto-Scroll & Load All to load older posts, then click Download All.
  4. Photos and videos are saved to Downloads/Nursery_Photos/ with original capture dates embedded.
