Install Manually from the GitHub Repository

While store listings are pending, you can generate and load the extension directly from the GitHub repository.

Step 1: Export the Extension Package

  1. Clone or download the repository and install dependencies (requires Node.js):
git clone https://github.com/rob-n-f/Nursery-Browser-extension.git
cd Nursery-Browser-extension
npm install
npm run dev
  1. Open http://localhost:3000 in your browser and go to the Store Publishing Kit tab.
  2. Download the package for your browser:
    • Chrome / Edge: nursery-media-downloader-chrome-edge-mv3.zip
    • Firefox: nursery-media-downloader-firefox-mv3.zip
  3. Unzip the downloaded .zip file into a permanent folder on your computer.

Step 2A: Load in Google Chrome or Microsoft Edge

  1. Open chrome://extensions (or edge://extensions in Edge).
  2. Turn on the Developer mode toggle (top-right corner).
  3. Click Load unpacked.
  4. Select the unzipped nursery-media-downloader-chrome-edge-mv3 folder.

Step 2B: Load in Mozilla Firefox

  1. Open about:debugging#/runtime/this-firefox in Firefox.
  2. Click Load Temporary Add-on….
  3. Select the manifest.json file inside the unzipped Firefox folder (or select the .zip file directly).

How to Use After Installing

  1. Log in to Bright Horizons FamilyApp or Famly and open your child's Learning Journey or Newsfeed.
  2. Click the floating Download Media button in the bottom-right corner (or click the extension icon in your browser toolbar).
  3. Optionally click Auto-Scroll & Load All to load older posts, then click Download All.
  4. Photos and videos are saved to Downloads/Nursery_Photos/ with original capture dates embedded.
